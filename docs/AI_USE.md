# AI assistance and scientific boundaries

AI development tools, including Claude Code and OpenAI Codex, assisted with
implementation, refactoring, automated checks and documentation. Product choices,
mission assumptions and interpretation of results remain human responsibilities.

The in-app Chader Buri guide uses Google Gemini to explain the selected mission
and offer navigation. API keys remain on the server. The guide receives the
application's calculated context and cannot establish flight readiness or
guarantee a radio connection.

## Numerical results

Positions, visibility, terrain horizons, battery balance and other engineering
estimates are calculated by deterministic project code. Scientific inputs come
from the credited NASA/JPL datasets and reference documents. A language model
does not produce the numerical mission predictions.

See [the scientific model](SCIENCE.md) and
[the external benchmark audit](BENCHMARK_AUDIT.md) for assumptions, validation
scope and remaining limitations.

## Visual material

Measured terrain and astronomical inputs are distinguished from illustrative
surface detail, equipment, character art and appearance textures. Source credits
and applicable licenses remain in the README and bundled provenance manifests.
The surface material's scope is described in
[Surface experience](SURFACE_EXPERIENCE.md).

The project is an independent educational and preliminary screening tool. It is
not NASA-endorsed or a substitute for mission-specific engineering review.
